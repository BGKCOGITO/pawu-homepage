# PAWU Hospital Landing v1.4

병원 우편 QR 유입과 무료 체험 전환을 위해 PAWU 공식 홈페이지를 전면 개편한 버전입니다.

## 핵심 변경
- PAWU의 따뜻한 크림·코랄·민트 브랜드 디자인 강화
- 실제 PAWU 로고 적용
- 예약 → 내원 → 진료 → 진료 완료의 실무 흐름을 스크롤형 콘텐츠로 구성
- 병원과 보호자의 각 단계 행동을 구분하여 설명
- 채팅, 전자차트, 입원 경과, 알림, 반려동물 정보, 진료 후 기록 연결 소개
- “PAWU는 아직 완성된 프로그램이 아닙니다. 원장님의 의견으로 계속 발전하는 서비스입니다.” 반영
- 무료 체험 신청 폼과 대표 연락처 추가
- PC·모바일 반응형 적용

## GitHub 업로드
압축을 풀고 내부 파일 전체를 기존 PAWU 홈페이지 저장소에 덮어쓴 뒤 커밋합니다.
