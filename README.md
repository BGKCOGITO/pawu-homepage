# PAWU Homepage QR Landing v1.3

병원 우편의 QR 코드가 연결될 PAWU 공식 홈페이지 개편본입니다.

## 주요 변경
- 첫 화면에 `PAWU란? / 진료 흐름 / 무료 체험` 빠른 선택 메뉴 추가
- 예약 → 내원 → 진료 → 진료 완료 과정을 웹 포스터 형식으로 구성
- 병원·보호자 채팅, 전자차트, 입원 경과, 알림 등 핵심 기능 정리
- “PAWU는 아직 완성된 프로그램이 아닙니다. 원장님의 의견으로 계속 발전하는 서비스입니다.” 메시지 반영
- 무료 체험 신청 폼 추가
- 대표 연락처 010-3015-2717 / bgkcogito@naver.com 반영
- 기존 따뜻한 PAWU 디자인과 모바일 반응형 유지

## 체험 신청 폼 안내
현재 신청 버튼은 사용자의 이메일 앱을 열어 작성 내용을 `bgkcogito@naver.com`으로 전송하는 방식입니다.
추후 Supabase 저장 방식으로 연결하면 이메일 앱 없이 홈페이지에서 바로 접수할 수 있습니다.

## 업로드
압축을 풀고 내부 파일 전체를 기존 GitHub 저장소에 덮어쓴 뒤 커밋하면 Vercel에서 자동 배포됩니다.
