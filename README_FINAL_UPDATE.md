# PAWU 공식 홈페이지 최종 수정

## 반영 내용
- 병원과 보호자가 PAWU를 왜 한 번 사용해봐야 하는지 중심으로 전체 문구·구조 개편
- 병원용 기능과 보호자용 기능을 분리해 설명
- 기존 프로그램을 교체하지 않고 병행 체험할 수 있다는 점 강조
- 예약 → 내원 → 진료·입원 → 진료 후 기록 흐름을 직관적으로 안내
- 병원 무료 체험, 보호자 서비스, 병원 프로그램 다운로드 CTA 정리
- 다운로드 센터를 공식 설치파일·설치순서·업데이트·FAQ 중심으로 개편

## 다운로드 파일 보존
`public/downloads/PAWU.Hospital_0.1.6_x64-setup.exe` 파일은 원본과 동일하게 보존되어 있으며 다운로드 버튼에 직접 연결되어 있습니다.

## 배포
```powershell
npm install
npm run build
vercel --prod
```
